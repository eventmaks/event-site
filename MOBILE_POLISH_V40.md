# Mobile Polish V40

Изменения только по последнему запросу:

1. Нижняя правовая часть на мобильной версии сильно уменьшена:
   - меньше отступов;
   - меньше шрифты;
   - ссылки на политику/согласие больше не занимают по 44px каждая.

2. Страницы privacy.html и consent.html на телефоне стали значительно компактнее,
   при этом юридический текст не удалялся.

3. Cookie-баннер:
   - маленький;
   - слева снизу;
   - не блокирует сайт;
   - кнопка «Я СОГЛАШАЮСЬ»;
   - новый localStorage key v5, чтобы баннер снова появился после обновления.

4. «Рассчитать стоимость»:
   - возвращена на мобильную версию;
   - постоянно остаётся на экране при прокрутке;
   - лёгкое плавание вверх/вниз;
   - пульсирующее кольцо;
   - ведёт к #calculator.

Desktop-верстка основных секций не менялась.
