# Benefits + Contract Visual V1

Усилены только два блока: «Что вы получите» и «Договор».

## Что вы получите
Существующая утверждённая механика карточек V4 НЕ менялась:
- карточки по-прежнему появляются из pale-blue ghost state;
- вертикальная линия рисуется по мере открытия;
- при скролле вверх всё точно откатывается назад.

Добавлен только второй визуальный слой:
- очень слабое движение бордовой кляксы;
- крупное фоновое слово «СПОКОЙНО»;
- рукописный акцент «ВСЁ ПОД КОНТРОЛЕМ»;
- маленькие editorial-labels у карточек;
- лёгкая глубина теней при полном проявлении.

## Договор
Сохранено:
- положение белого листа внутри бордовой рамки;
- существующая SVG-траектория сердца;
- движение ручки точно по пути сердца;
- позднее начало подписи;
- реверс при обратном скролле.

Добавлено:
- мягкое «приземление» всей сцены с договором;
- более естественная тень под бумагой;
- микродвижение бумаги не больше нескольких пикселей;
- очень слабое движение фоновой кляксы;
- две небольшие маркировки около документа;
- kicker над заголовком;
- рисованная подпись-стрелка под заголовком;
- небольшая тень у ручки.

Остальные секции сайта не изменялись.
