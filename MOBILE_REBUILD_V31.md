# Mobile Rebuild V31 — реальное движение «СОЗДАЮ СОБЫТИЯ»

Предыдущие CSS-анимации на iPhone всё равно визуально не двигались.

Поэтому в V31 механизм полностью заменён:
- CSS-анимации для этих строк отключены;
- движение выполняет JavaScript через requestAnimationFrame;
- каждая строка получает реальный translate3d;
- нечётные строки двигаются влево;
- чётные — вправо;
- расстояние цикла считается по реальной ширине повторяющегося текста,
  поэтому переход бесшовный;
- анимация работает только когда блок находится рядом с viewport,
  чтобы не грузить телефон.

Изменён только мобильный фон «СОЗДАЮ СОБЫТИЯ».
