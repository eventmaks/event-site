# Mobile Rebuild V27

Точечная доводка уже новой архитектуры V26.

## Моя команда
- убран искусственный `min-height: 930px`;
- секция теперь заканчивается по реальному содержимому;
- уменьшены верхний/нижний padding;
- уменьшены вертикальные промежутки между двумя рядами;
- фон `МОЯ КОМАНДА` продолжает двигаться на всю секцию;
- нижний marquee сохранён, но занимает меньше пустого пространства.

## Мопс
- увеличен с 108px до 124px;
- остаётся в обычном потоке ниже/справа от карточки;
- не перекрывает список, кнопку и нижнюю подпись;
- вкусняшка увеличена пропорционально.

Все изменения только в `mobile-rebuild.css`.
Desktop и Portfolio не изменялись.
