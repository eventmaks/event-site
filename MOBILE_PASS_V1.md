# Mobile Pass V1

Проведён отдельный проход по мобильной версии на ширинах 320–430 px.

## Исправлено

### Hero
На 320 px имя выходило за левую и правую границу экрана.
Для узких телефонов уменьшен размер заголовка и исправлена его ширина.

### «Обо мне»
На 320 px «ДАВАЙТЕ ЗНАКОМИТЬСЯ!» обрезалось справа.
Добавлен отдельный narrow-phone размер заголовка.

### Плавающая кнопка «Рассчитать стоимость»
На телефоне 75 px кнопка перекрывала:
- текст «Обо мне»;
- карточки квиза;
- стоимость;
- FAQ;
- финальный экран.

Теперь она 56 px и автоматически скрывается в плотных секциях:
About, Quiz, Benefits, Contract, Cost, FAQ, Contact.
На Team / Portfolio / Reviews она остаётся доступной.
Desktop не изменён.

### Отзывы
Автоматический горизонтальный scroll-drift сдвигал первую карточку за левый край.
На мобильном drift отключён; стрелки продолжают работать.
Стрелки увеличены с 36×36 до 44×44 для удобного нажатия.

### Финальный телефон
Старое правило `.contact-mail` конфликтовало с новым интерфейсом и делало
Email огромной плиткой. Email теперь такой же четвёртый app-icon, как
Call / WhatsApp / Telegram.

Также:
- контактные иконки 44×44;
- подписи немного крупнее;
- footer корректнее переносится на 320 px;
- caption с почтой не вылезает за экран.

### Showreel
Кнопка управления звуком получила минимальную высоту 44 px.

## Проверки
- Portfolio не изменён ни на один символ внутри секции.
- JavaScript: `node --check` — OK.
- Дублирующихся id — 0.

Следующий этап после утверждения мобильной геометрии:
оптимизация веса Showreel / изображений и локализация Pexels-фото в assets.
