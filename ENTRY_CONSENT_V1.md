# Entry Consent V1

При первом входе на сайт показывается модальное окно.

Пользователь может:
- «СОГЛАСЕН» — согласие сохраняется в localStorage;
- «ПРОДОЛЖИТЬ БЕЗ СОГЛАСИЯ» — сайт остаётся доступен;
- закрыть окно крестиком — считается продолжением без согласия.

Если пользователь согласился при входе, чекбокс на последнем шаге квиза
автоматически отмечается.

Если пользователь отказался, сайт всё равно доступен, а согласие можно
дать позже непосредственно перед отправкой формы.

Это сделано намеренно, чтобы согласие оставалось добровольным.
