# Portfolio — no hover tools

Изменён только способ отображения 9 фотографий Portfolio:
- вместо обычных `<img>` используются CSS-background;
- браузер больше не должен показывать поверх них кнопку/подсказку поиска изображения («Яндекс Картинки»);
- отключены hover, zoom, click/tap-реакции на фото;
- курсор над фото ничего не запускает.

Сетка, размеры, порядок фотографий и фоновое слово «ПОРТФОЛИО» сохранены.
