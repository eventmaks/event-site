# Mobile Hero Fixed V8

Найдена конкретная причина, почему фотография на телефоне продолжала
оставаться справа и выглядела как старая версия.

В старом CSS присутствовало:
`body.hero-ready .portrait { transform:none!important; }`

А новый mobile CSS задавал:
`.portrait { left:50%; transform:translateX(-50%)!important; }`

Из-за большей специфичности старого селектора transform сбрасывался.
Итог: фотография начиналась с 50% ширины экрана и большая часть человека
уходила вправо за экран.

V8:
- переопределяет portrait селектором более высокой/равной специфичности;
- жёстко центрирует фото на iPhone;
- уменьшает его до 96vw / max 390px;
- показывает весь доступный торс;
- отключает конфликтующие transform/animation на mobile portrait;
- добавляет ?v=8 к CSS и JS, чтобы мобильный браузер не показывал старый кэш.

Desktop и Portfolio не изменялись.
