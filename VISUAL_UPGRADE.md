# Visual Upgrade V1

Первый проход по визуализации сделан для трёх утверждённых секций:
«Обо мне», «Команда», «Портфолио».

## Обо мне
- фото Максима получило лёгкий scroll-parallax;
- на desktop фото очень мягко реагирует на движение курсора;
- добавлены два факт-бейджа: «8+ лет в событиях» и «100+ мероприятий»;
- добавлена рукописная стрелка «Спокойно. По делу.»;
- добавлен небольшой штамп «Без шаблонов»;
- фоновые строки слегка двигаются при прокрутке.

## Команда
- утверждённая сетка 3 + 2 НЕ менялась;
- имена и фотографии НЕ менялись;
- фоновые строки «МОЯ КОМАНДА» теперь имеют небольшой разнонаправленный drift;
- на desktop фотографии чуть приподнимаются/наклоняются при наведении;
- имя получает рисованное подчёркивание;
- добавлены очень небольшие голубые маркерные акценты.

## Портфолио
- композиция и размеры утверждённой галереи НЕ менялись;
- фотографии получили мягкий внутренний параллакс;
- добавлена небольшая нумерация кадров;
- между группами появились редакционные подписи «ЛЮДИ / ЭМОЦИИ / ДЕТАЛИ»;
- hover делает кадр немного глубже;
- нижняя фоновая надпись «ПОРТФОЛИО» слегка движется при скролле.

## Производительность
Все scroll-эффекты работают в одном requestAnimationFrame цикле.
На prefers-reduced-motion дополнительные движения отключаются.
