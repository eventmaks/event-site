# Mobile Strict Desktop Parity V20

## Что было ошибкой

1. На мобильной версии накопилось несколько поколений `@media`-правил. Одни правила отключали desktop-анимации, следующие пытались включить часть обратно. Из-за этого mobile выглядел как отдельный упрощённый сайт.
2. Блок «СОЗДАЮ СОБЫТИЯ» был растянут в большой мобильный постер: фото стало слишком крупным, фоновые строки редкими. На desktop пропорции совершенно другие.
3. Команда была переделана в 2+1+2, хотя desktop-композиция — 3+2. Это меняло характер секции.
4. Много декоративных desktop-слоёв на телефоне были скрыты: benefits ambient/doodle, contract notes, часть texture density.
5. Мопс на mobile был вынесен отдельной строкой, хотя desktop-композиция — карточка по центру + мопс справа.
6. Ранее mobile использовал статические финальные состояния для ряда scroll-visual. V19 уже вернул JS-механику, V20 сохраняет её и выравнивает композицию.

## Принцип V20
Не делать отдельный mobile-дизайн. Сохранять desktop-композицию и механику и только пропорционально уменьшать/перекомпоновывать то, что физически не помещается в 320–430px.

## Ключевые изменения
- About: точнее масштабированы desktop-пропорции; фото меньше, строки плотнее и двигаются все.
- Team: 3 карточки сверху + 2 снизу, как desktop.
- Benefits: возвращены декоративные desktop-слои.
- Contract: возвращены заметки и бумажная глубина.
- Cost: карточка по центру, мопс справа, а не отдельным блоком снизу.
- Все scroll-анимации из V19 сохранены.
- Portfolio markup не менялся.
- Consent V17 сохранён.

Cache bust: v20.
