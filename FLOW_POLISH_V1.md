# Flow Polish V1 — полный проход по странице

Добавлены только переходы между уже готовыми сценами.

## Новые переходы
1. «Команда» → «Портфолио»
   Тёплый фон мягко уходит в бордовый, появляется небольшая рисованная стрелка.

2. «Портфолио» → «Квиз»
   Бордовый заканчивается неровной бумажной границей и переходит в тёплый фон квиза.

3. «Договор» → «Стоимость»
   Тёплая сцена переходит в голубую через мягкую волну.

4. «FAQ» → финальный контакт
   Голубой фон мягко раскрывается в тёплый финальный экран.

Все переходы связаны со скроллом и рисуются постепенно.
